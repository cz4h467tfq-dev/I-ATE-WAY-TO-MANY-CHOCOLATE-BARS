# Bayt Kfarchima · WELNOVA Week 1

A first-person walk through a Lebanese house in Kfarchima, built for the eTwinning project **WELNOVA** (Collège Notre Dame des Sœurs Antonines – Kfarchima).

- `index.html`, `style.css`, `app.js`, `art.js`: the house, made with CSS 3D (no libraries). Anna the ghost guides you through nine rooms, points at objects and pops each piece of information up in front of you. The arch to the next room opens only after you have read every card.
- `assets/welnova-school.glb`: the WELNOVA Eco-Future School, shown in 3D and AR with Google's model-viewer. Rebuild it with `python3 tools/make_school_glb.py`.
- "Read as page" shows all the content as a normal scrolling page.
